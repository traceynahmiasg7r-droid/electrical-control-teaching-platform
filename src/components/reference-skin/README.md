# 原图元件外观

这两张 JPG 为用户提供的视觉参考原文件，未经过重绘、生成或图像滤镜。
共享元件库通过 SVG viewBox 裁切显示其中的元件区域，保留原图细节和长宽比。
源坐标定义在 electrical-simulation-primitives.js 的 referenceSlice 调用中。

电流路径、颜色、速度、控制事件、求解器、联锁和回放沿用第一版。
触点闭合、按钮按压、电机运转和热保护动作通过独立状态层显示。
尺寸受现有画布与接线端点约束，浏览器缩放时原始 JPG 会进行插值；并非无限分辨率矢量素材。
没有示例的元件（如 SA 转换开关、时间标记）保留现有状态表达。
